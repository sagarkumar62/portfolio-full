## 🛠️ Technology Stack

- **Framework**: Next.js 15 (App Router, Static Export compatible)
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS v4 with bespoke metallic & chrome design tokens
- **3D & WebGL**: Three.js & React Three Fiber with zero-layout-shift CSS fallbacks
- **Icons**: Lucide React
- **Email Service**: EmailJS Integration

## 🚀 Running Locally

```bash
# Install dependencies
npm install --legacy-peer-deps

# Run local development server
npm run dev

# Run production build and static export
npm run build
```

Production output will be generated in the `/out` directory, ready for Netlify or Vercel static deployment.
